# Prison Escape

## Om spillet
Prison Escape er et tekstbasert spill laget i Python. Spilleren starter i en fengselscelle og må ta forskjellige valg for å prøve å rømme fra fengselet.

## Hvordan spille
1. Start spillet ved å kjøre main.py.
2. Les teksten som vises i terminalen.
3. Velg mellom alternativ 1 og 2.
4. Prøv å finne riktig vei ut av fengselet.
5. Hvis du velger feil, taper du spillet.

## Filer
main.py – Inneholder hovedkoden og spillmekanikken.
images.py – Skal brukes til å håndtere bilder i spillet.
README.md – Informasjon om prosjektet.

## Målet med spillet
Målet er å komme seg ut av fengselet ved å ta riktige valg. Noen valg fører til at du taper, mens andre fører deg nærmere friheten.
